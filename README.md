# Minecraft Server Guide Plugin

Galactic Horizons is a Minecraft server plugin that provides in-game guidance for a technology-focused modpack centered on Create, Create Aeronautics, Applied Energistics 2 (AE2), and layered tech progression. It adds the `/techpack` command with starter advice and suggested progression stages.

## Install

1. Build the project with Java 21 and Maven: `mvn package`.
2. Copy `target/plugin.jar` into your Paper server’s `plugins` directory.
3. Restart the server.

## Use

- Run `/techpack` or `/techpack help` to view the guide overview.
- Run `/techpack start` for starter advice.
- Run `/techpack progression` for suggested progression stages.
- Type `/techpack` followed by a space to see available command options.
